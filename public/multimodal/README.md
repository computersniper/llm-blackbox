# 多模态模型可视化

展示 Qwen 视觉语言模型如何理解图像的交互式页面。

## 功能特点

### 三种视图模式

1. **切块视图** - 展示图像如何被切分为 14×14 的块
2. **词元视图** - 显示图像块如何转换为词元输入语言模型
3. **注意力视图** - 可视化模型生成每个字时关注的图像区域

### 交互功能

- 选择不同示例图片
- 逐字播放模型回答
- 查看每个字对应的注意力分布
- 悬停查看图像块的详细信息

## 技术实现

- 基于 Canvas API 绘制图像
- 模拟 Qwen-VL 的图像处理流程
- 生成合理的注意力分布数据
- 与主页面相同的设计风格

## 使用说明

1. 点击左侧示例图片进行选择
2. 点击播放按钮逐字查看回答
3. 切换不同视图模式观察不同阶段
4. 在注意力视图中，高亮区域表示模型正在关注的图像部分

## 扩展

可以通过以下方式扩展功能：

- 添加真实的 Qwen-VL 模型数据
- 支持用户上传自定义图片
- 显示更详细的中间层激活
- 添加 3D 可视化效果
