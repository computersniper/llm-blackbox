# 多模态模型可视化

多模态页沿用推理页的选择页、调试器、面包屑与单步控制。选择一张照片后可依次查看预处理、视觉编码器、图文词元进入语言模型，以及模型逐词元生成的回答。点击图像网格可检查每个视觉词元的实测向量摘要。

数据由 `tools/export_multimodal.py` 从本地 Qwen2-VL-2B-Instruct 导出。脚本要求完整权重与 CUDA；模型或注意力提取失败即报错。它不提供模拟回退。四张照片的记录已导出，旧版随机数据已移除。

视觉网格由该次输入的 `image_grid_thw` 确定，14 像素原始块经过 2×2 空间合并。页面只展示视觉编码器最终输出，不含 ViT 中间层。热图为**语言模型最后一层自注意力**所有头的平均值，也可逐头查看，显示生成某个词元时到各图像词元的权重。图像内部权重归一化后便于比较，也单独给出图像词元在总注意力中的占比。注意力不是因果解释。
